# 酒店管理系统 - 组件功能说明文档

## 项目概述
本项目是一个完整的酒店管理系统，采用 Vue 3 + Element Plus + Vite 技术栈构建，提供酒店日常运营管理的完整解决方案。

## 技术架构
- **前端框架**: Vue 3 + Composition API
- **UI组件库**: Element Plus
- **构建工具**: Vite
- **路由管理**: Vue Router
- **HTTP客户端**: Axios
- **数据存储**: JSON Server (模拟后端API)

## 详细组件功能说明

### 1. 核心布局组件

#### Home.vue - 主布局容器
**功能职责**:
- 定义应用整体三维布局结构 (Header + Aside + Main)
- 使用 Element Plus Container 布局系统
- 通过命名路由视图实现模块化渲染

**核心特性**:
- 响应式布局设计
- 统一样式主题（深色侧边栏，浅色主内容区）
- 全屏高度适配

#### Header.vue - 顶部导航栏
**功能职责**:
- 显示系统Logo和名称
- 提供主导航菜单（首页、房态中心、预订管理、住房管理）
- 展示用户登录状态和信息
- 实现退出登录功能

**核心特性**:
- 多标签页登录状态同步
- 用户头像和状态显示
- 导航菜单高亮指示
- 安全的登出流程

#### Aside.vue - 侧边栏容器
**功能职责**:
- 根据当前路由动态显示对应的侧边菜单
- 实现菜单组件的懒加载
- 提供无刷新菜单切换体验

**核心特性**:
- 路由驱动的菜单切换
- 组件懒加载优化性能
- 模块化菜单管理

#### Login.vue - 登录页面
**功能职责**:
- 用户身份验证和登录
- 表单验证和错误处理
- 后端API用户认证
- 登录状态持久化

**核心特性**:
- 完整的表单验证机制
- 安全的密码处理
- 移动端适配
- 自动填充注册用户名
- 错误状态友好提示

### 2. 主要功能模块

#### Main.vue - 仪表板主页
**功能职责**:
- 展示系统概览信息
- 数据可视化图表展示
- 实时数据统计和趋势分析
- 快速导航入口

**数据展示**:
- 用户信息面板
- 今日入住/退房统计
- 房间状态和入住率
- 房间类型分布饼图
- 近7天入住退房趋势线图

**核心特性**:
- ECharts 数据可视化
- 响应式图表布局
- 实时数据更新
- 窗口大小自适应

#### room-center.vue - 房态中心
**功能职责**:
- 显示所有房间的状态和基本信息
- 支持多条件筛选（房型、楼层、状态）
- 通过路由参数实现动态筛选
- 点击房间跳转到详情页面

**状态管理**:
- 🔴 已入住 (红色边框)
- 🟢 空闲可用 (绿色边框)
- ?? 待清洁 (橙色边框)
- ⚫ 需要维修 (灰色边框)
- 🟣 已预订 (紫色边框)

**核心特性**:
- 基于路由参数的动态筛选
- 可视化房间状态标识
- 交互式房间卡片设计
- 实时状态反馈

#### booking.vue - 预订管理
**功能职责**:
- 预订记录的完整CRUD操作
- 多条件搜索和筛选功能
- 预订状态全生命周期管理
- 与房间状态实时同步

**预订状态流转**:
- 未入住 → 已入住/已取消
- 已入住 → 已完成

**核心特性**:
- 完整的状态管理机制
- 实时数据同步
- 批量操作支持
- 表单验证和提交
- 分页显示和搜索

#### housing-home.vue - 住房管理主页
**功能职责**:
- 显示所有已入住客人信息
- 提供搜索框进行关键字搜索
- 支持房间信息修改功能
- 退房操作入口

**新增功能** (最近更新):
- 🔍 **搜索功能**: 支持按房间号、房型、入住人姓名、联系方式搜索
- ✏️ **修改功能**: 弹出对话框修改客人信息（姓名、联系方式、入住时间）
- 📊 **分页优化**: 使用过滤后的数据进行分页显示

**核心特性**:
- 表格数据展示
- 实时搜索筛选
- 分页数据管理
- 弹窗式编辑界面

## 数据流和状态管理

### API数据流程
- 所有组件通过 Axios 与 `http://localhost:3000` 的 JSON Server 通信
- 主要数据端点: `/rooms`, `/booked`, `/users`, `/dailyStats`
- 实时数据同步确保状态一致性

### 状态管理机制
- 本地状态使用 Vue 的 ref/reactive
- 登录状态通过 sessionStorage 持久化
- 路由参数驱动筛选和导航
- 计算属性实现数据过滤和分页
